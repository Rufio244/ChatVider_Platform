# 🚀 คู่มือปรับใช้งานระบบ Chat Vider

## 📋 ขั้นตอนเตรียมความพร้อม
1. สร้างคลังใหม่บน GitHub ชื่อ `ChatVider_Platform`
2. อัปโหลดทุกโฟลเดอร์และไฟล์ตามโครงสร้าง
3. กำหนดค่าลับในส่วนการตั้งค่าคลัง/โฮสต์

---

## ☁️ วิธีที่ 1: ปรับใช้ผ่าน Vercel
1. เข้า Vercel → เพิ่มโปรเจกต์ → นำเข้าจาก GitHub
2. เลือกคลัง `ChatVider_Platform`
3. ในส่วน Environment Variables เพิ่มตามไฟล์ `.env`
4. กดปรับใช้งาน รอสักครู่ก็เสร็จเรียบร้อย

---

## 🖥️ วิธีที่ 2: รันบนเครื่องหรือเซิร์ฟเวอร์เอง
### ใช้คำสั่งปกติ
```bash
# ลินุกซ์/แมค
chmod +x install.sh
./install.sh
npm start

# วินโดว์
คลิกไฟล์ start.bat
