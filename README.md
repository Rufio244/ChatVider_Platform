## 📦 เริ่มต้น
1. คัดลอก `.env.example` เป็น `.env` แล้วกรอกข้อมูล
2. รัน `npm install`
3. รันระบบ: `npm start`

## ⚠️ สำคัญ
- นี่คือหัวสมองใหม่โดยสมบูรณ์ ไม่ใช่ส่วนหนึ่งของ Vider AGI
- เริ่มต้นว่างเปล่า เรียนรู้จากการใช้งาน
- สิทธิ์สูงสุดเป็นของเจ้าของผู้สร้างแต่เพียงผู้เดียว
